# Yuki-Kiss-Game

This is one of the minigames in Date-ify, in this game you have to kiss Yuki when you are not being looked at.
You win by getting 1000 points and lose if you are seen.

To build this run

```
g++ main.cpp -o main -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
```

Or

Download the .exe from the releases.

> [!NOTE]
> You need raylib installed on your system to build the file

> [!WARNING]
> This has not been tested on Windows or MacOs
